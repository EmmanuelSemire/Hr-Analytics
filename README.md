# HR Analytics

## Project Overview

This project analyzes employee data to understand workforce demographics, promotion status, retrenchment, tenure, job levels, distance from work, and employee engagement.

The data was cleaned and prepared in Excel, analyzed using MySQL, and visualized through an interactive Power BI dashboard.

## Key Metrics

- Total Employees: 1,470
- Active Employees: 1,353 (92%)
- Retrenchment/Separation: 117 (8%)
- Due for Promotion: 72 (5%)
- Male: 882 (60%)
- Female: 588 (40%)

## Key Insights

- R&D had the highest number of employees affected by retrenchment and promotion.
- The workforce was concentrated at Job Levels 1 and 2, with 543 and 534 employees respectively.
- Employees with 1 and 5 years of service represented the largest tenure groups.
- 63.95% of employees lived very close to their workplace.
- Overall job satisfaction and overtime rating was recorded at 84.6%.

## Tools Used

- Excel — Data cleaning and preparation
- MySQL — Data querying and analysis
- Power BI — Data visualization and dashboard development
